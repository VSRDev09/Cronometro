# ⏳ Criando um **Cronômetro** com C# e Windows Forms  

## 🎯 **Descrição do Projeto**  
Desenvolvi um **cronômetro funcional** utilizando **C#** e a biblioteca **Windows Forms**! 🎉 Esse projeto permite:  
✅ Exibir a hora atual em tempo real.  
✅ Alternar entre **modo relógio** e **modo cronômetro**.  
✅ Iniciar, pausar e zerar a contagem.  
✅ Interface personalizada com botões arredondados.  

---

## 🛠 **Tecnologias Utilizadas**  
- **C#** 💻  
- **Windows Forms (WinForms)** 📟  
- **.NET Framework** 🔧  
- **Programação Orientada a Objetos (POO)** 🏛  

---

## 🚀 **Funcionalidades do Cronômetro**  
### 🕒 **Modo Relógio**  
Quando o cronômetro está desligado, ele exibe a **hora atual do sistema** em tempo real.  

### ⏱ **Modo Cronômetro**  
Ao ativar o modo cronômetro, é possível:  
✅ **Iniciar** a contagem do tempo.  
✅ **Parar** e retomar a contagem.  
✅ **Zerar** o tempo e reiniciar do zero.  

---

## 🎨 **Interface Gráfica (GUI)**  
💡 Para tornar o cronômetro mais visualmente agradável, implementei **botões arredondados** personalizados com **C# e GDI+**.  

🔹 **Biblioteca Windows Forms:** usada para criar a interface do usuário.  
🔹 **Classe personalizada para botões ovais:** melhora o design e usabilidade.
